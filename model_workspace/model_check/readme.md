此文件里面：
① 输入的物理格式（和模型无关，是硬件约束）
sampledata.h 告诉你的唯一一件重要的事：
你要喂给 CNN 的 16384 个数，在板子内存里不是平铺的。是 16 块 × 256 个 32 位字，4 个通道压进一个字，双 pass 交错。
这个格式跟模型无关。 它由两件事决定：MAX78000 的 HWC 数据格式 + 你有 128 个输入通道。你训自己的模型，输入还是 128×128，输出还是这 16 块。
所以这条规则你必须在自己的代码里实现一次。 官方这份文件就是它的说明书。

② 输出的物理格式
sampleoutput.h 告诉你：
输出是 {地址, 掩码, 长度, 值…} 的四元组序列，末尾 0 终止。
你的 2 类模型会长成 {地址A, 0xffffffff, 1, s0, 地址B, 0xffffffff, 1, s1, 0} —— 值不同，规则一样。

官方示例的一对输入-输出。负责进行校准物理地址和排查格式问题
